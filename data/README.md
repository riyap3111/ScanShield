# Data

## Source
**CICIDS2017** intrusion detection evaluation dataset, Canadian Institute for Cybersecurity (CIC), University of New Brunswick.
Flow features were extracted with CICFlowMeter from lab-generated traffic (no real user data).

- Official page: https://www.unb.ca/cic/datasets/ids-2017.html
- Kaggle mirror used: https://www.kaggle.com/datasets/sateeshkumar6289/cicids-2017-dataset
- Citation: Sharafaldin, I., Lashkari, A. H., & Ghorbani, A. A. (2018). *Toward Generating a New Intrusion Detection Dataset and Intrusion Traffic Characterization.* ICISSP 2018.

The dataset is distributed by CIC for research use; please cite the paper above.

## The files are not committed

The eight CSVs total about 1.0 GB (65 MB even gzipped for the two main ones), which is past what
belongs in a git repository. `data/raw/` is git-ignored. Download the files yourself from either
link above and verify them against the SHA256 values below, which are the exact files every
number in the reports was produced from.

```bash
shasum -a 256 <file>.csv        # macOS
sha256sum <file>.csv            # Linux
```

### Generalization testing — place in `~/Desktop/CICIDS_dataset/`

Steps `10_generalization.py` and `13_monitoring.py` score the model on every other capture day:
2.5 million flows and twelve attack types that never appear in training. They read the original
uncompressed CSVs from this folder and skip themselves with a message if it is absent.

**Schema note.** The files are not drop-in identical. Every header has leading whitespace; the
web-attacks file is cp1252-encoded, not UTF-8, so its `Web Attack – Brute Force` labels fail a
plain UTF-8 read. `src/10_generalization.py` audits and reports these differences before scoring
rather than silently coercing them.

## `processed/` (not committed, regenerated by `run_all.sh`)
- `portscan_clean.parquet` — cleaned main data (213,602 rows)
- `monday_benign_clean.parquet` — cleaned Monday data
- `split_indices.parquet` — stratified and time-ordered train/val/test assignment per row
- `model_matrix.parquet`, `monday_matrix.parquet` — the above plus the engineered features
- `models/*.joblib` — fitted models
